# IPL Dashboard

A responsive React application to explore IPL teams and their latest match statistics. Clicking on a team card shows detailed match info with dynamic routing.

## Features

- Fetches teams and match data from public APIs
- Displays team banners, latest match, and recent matches
- Dynamic route for team pages: `/team-matches/:id`
- Loader shown while fetching data
- Responsive and team-themed background styling

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/IPLDashboard
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Open in your browser:

   ```
   http://localhost:5173
   ```
