# Letters Calculator

A simple React app that calculates and displays the number of letters typed into an input field. It updates the letter count in real-time as the user types.

## Features

- Real-time letter count based on input  
- User-friendly layout and responsive design  
- Clean UI with a calculator-themed image

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/LettersCalculator
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app using Vite:

   ```bash
   npm run dev
   ```

3. View the app at:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- State management in React
