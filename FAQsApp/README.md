# FAQs App

An interactive React application that presents frequently asked questions. Each FAQ can be expanded or collapsed individually by toggling a plus/minus icon. This project demonstrates conditional rendering, state management, and dynamic UI behavior using class-based components.

## Live Demo

- [FAQs App Live](https://faqsak.ccbp.tech)

## Features

- Dynamic rendering of FAQ items using props
- Plus/minus icons to toggle visibility of answers
- Each FAQ maintains its own expand/collapse state
- Clean component-based structure

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/FAQsApp
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- React class components
- State toggling using `setState`
- Conditional rendering with boolean flags
- List rendering with `.map()`
- Controlled UI behavior per component
