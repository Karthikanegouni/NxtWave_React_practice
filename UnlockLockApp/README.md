# Unlock/Lock App

A simple React app demonstrating state management with hooks to toggle between locked and unlocked device states.

## Features

- Displays a lock image and “Your Device is Locked” text on initial load
- Shows an **Unlock** button to change state to unlocked
- On clicking **Unlock**, displays an unlock image and “Your Device is Unlocked” text
- Shows a **Lock** button to toggle back to locked state
- Toggles seamlessly between locked and unlocked UI states

## Technologies Used

- Vite
- React
- Styled Components for styling

## Setup and Running

1. Clone the repo:

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/UnlockLockApp
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open in browser:

```bash
http://localhost:5173
```
