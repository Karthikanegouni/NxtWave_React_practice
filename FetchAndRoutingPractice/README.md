# Fetch and Routing Practice

A React application demonstrating routing and API data fetching. Blogs are fetched from a remote server and displayed on the homepage. Clicking on a blog navigates to its detailed view using dynamic routing.

## Live Demo

- Demo Link => [BlogList App](https://blogappak.ccbp.tech/)

## Features

- Fetch blogs from API using `fetch`
- Show loader while fetching data
- Navigate to blog detail using `/blogs/:id`
- Display blog content with title, image, and author
- Fully responsive UI
- Built using both RFC and RCC components

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/FetchRoutingPractice
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Open in your browser:

   ```
   http://localhost:5173
   ```
