# Rock Paper Scissors

A React app to play the Rock, Paper, Scissors game and track your score.

## Live Demo

- ### [Live Link](https://rpsak.ccbp.tech/)

## Features

- Play classic Rock, Paper, Scissors against a random opponent
- Rules popup for quick reference
- Scoreboard updates after every round
- Responsive design for all device sizes
- Play again button for restarting the round

## Functionality

- Score starts at 0 and updates with wins/losses (win: +1, draw: 0, lose: -1)
- Choices are displayed with images and buttons for Rock, Paper, and Scissors
- Opponent choice is randomly selected
- Displays "YOU WON", "YOU LOSE", or "IT IS DRAW" after each round
- Play Again resets for a new round
- Rules button opens a modal explaining the game

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/RockPaperScissors
```

## Installation & Running

1. Install dependencies:

```bash
    npm install
```

2. Start the development server using Vite:

```bash
    npm run dev
```

3. Visit:

```bash
    http://localhost:5173
```
