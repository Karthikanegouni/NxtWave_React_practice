# Prime Video

A React app that displays Action and Comedy movie carousels, with a popup video player for each movie.

## Live Demo

- ### [Live Link](https://primevidak.ccbp.tech/)

## Features

- Action Movies and Comedy Movies sliders created with React Slick
- Carousel displays 4 thumbnails per frame, next/previous navigation supported
- Clicking a movie thumbnail opens popup to play video using React Player
- Responsive layout and smooth transitions
- Not Found route for invalid URLs

## Functionality

- Renders two movie carousels from a single moviesList data prop
- Carousels filter movies by category into Action and Comedy sections
- Clicking a thumbnail displays the video in a popup
- Close button dismisses the popup player

## Cloning This Project

    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
    cd NxtWave_React_practice/PrimeVideo

## Installation & Running

1. Install dependencies:

   npm install

2. Start the development server using Vite:

   npm run dev

3. Visit:

   http://localhost:5173
