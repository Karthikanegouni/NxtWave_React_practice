# Emoji Game

A fun and interactive memory-based React game. Click on unique emojis to increase your score. If you click the same emoji twice, you lose. Shuffle logic ensures the emoji order changes after each click. Try to win by clicking all emojis exactly once!

## Live Demo

- [Click here Play](https://emojigameakg.ccbp.tech/)

## Features

- Memory-based game logic
- Score increases on clicking a new emoji
- Game ends with Win or Lose screen
- Score resets after each round
- Top Score is retained between rounds
- Emojis shuffle after each click
- Responsive and styled using CSS

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/EmojiGame
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```
