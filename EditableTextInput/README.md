# Editable Text Input

A React app demonstrating conditional rendering with an editable text input that toggles between edit and display modes.

## Features

- Edit mode: input field and Save button are shown
- Display mode: saved text and Edit button are shown
- Seamless toggle between editing and viewing state
- Styled using styled-components
- Responsive design for all device sizes

## Functionality

- Initially shows an input box with a Save button
- On Save: input value becomes text, Edit button appears
- On Edit: input with current text appears again with Save button

## Cloning This Project

    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
    cd NxtWave_React_practice/EditableTextInput

## Installation & Running

1. Install dependencies:
   npm install
2. Start the development server using Vite:
   npm run dev
3. Visit:
   http://localhost:5173
