# Layout Builder App

A React app that lets users toggle visibility of Content, Left Navbar, and Right Navbar to customize the layout instantly.

## Live Demo

- ### [Live Link](https://layoutbuildak.ccbp.tech/)

## Features

- Instantly show/hide Content, Left Navbar, and Right Navbar using checkboxes
- Layout updates live as toggles are changed
- Context-based configuration and state management for layout sections
- Modular design using React components for Header, Body, Footer, and Controller
- Responsive across devices and screen sizes

## Functionality

- Content, Left Navbar, and Right Navbar are visible by default
- Unchecking a box hides the corresponding layout section
- Rechecking displays the hidden section again
- Configuration Context manages show/hide state and toggle handlers for each section

## Cloning This Project

```bash
    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
```

## Installation & Running

1. Install dependencies:

```bash
    npm install
```

2. Start the development server using Vite:

```bash
   npm run dev
```

3. Visit:

```bash
   http://localhost:5173
```
