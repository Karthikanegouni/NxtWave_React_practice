# Gradient Generator

A React app to create a custom linear gradient using color pickers and direction controls.

## Features

- Select gradient direction from a group of options
- Pick two colors using input color pickers
- Instantly preview the linear gradient background
- Generate button applies the selected settings
- Responsive design for all device sizes

## Functionality

- Direction defaults to the first item in the gradientDirectionsList
- Initial colors: #8ae323 and #014f7b
- Color picker values appear as captions below their pickers
- Clicking Generate applies the chosen direction and colors to the background
- Direction button opacity — active: 1, inactive: 0.5

## Cloning This Project

```bash
    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
    cd NxtWave_React_practice/GradientGenerator
```

## Installation & Running

1. Install dependencies:

```bash
   npm install
```

2. Start the development server using Vite:

```bash
   npm run dev
```

3. Visit:

```bash
   http://localhost:5173
```
