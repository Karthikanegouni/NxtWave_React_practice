# Alert Notifications

A React app displaying different types of alert notifications with icons and close functionality.

## Features

- Notifications with icon, heading, and description as children
- Uses react-icons for notification and close icons
- Supports Success, Error, Warning, and Info alerts
- Close button to dismiss notifications

## Cloning This Project

    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
    cd NxtWave_React_practice/AlertNotifications

## Installation and Running

1. Install dependencies:

   npm install

2. Start the development server using Vite:

   npm run dev

3. Open in your browser:

   http://localhost:5173

## Technologies Used

- React
- react-icons
- Vite
- CSS
