# Nxt Trendz – Protected Routes

A secure React app built with Vite that demonstrates route protection using JWT authentication.

## Live Demo

- ### [Protected Route](https://prorouteak.ccbp.tech/)

## Features

- JWT-based Login system
- Protected routes (Home, Products, Cart)
- Redirects unauthenticated users to Login
- Authenticated users can't access Login route
- Logout support
- Fast bundling with Vite

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/NxtTrendzProtectedRoute
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server with Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```
