# Projects Application

A categorized portfolio-style React app that displays a set of projects under three tabs: Static, Responsive, and Dynamic. Users can click on each tab to view filtered project listings with details and images.

## Features

- Three filter tabs: Static, Responsive, Dynamic
- Dynamically filters and displays relevant projects based on the selected tab
- Clean, responsive layout with reusable components
- Demonstrates state management and conditional rendering

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/ProjectsApplication
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app using Vite:

   ```bash
   npm run dev
   ```

3. Open in your browser at:

   ```
   http://localhost:5173
   ```
