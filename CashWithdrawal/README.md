# Cash Withdrawal

A simple React app that simulates a cash withdrawal system. This project helps understand props, state management, and event handling in React using class components.

## Features

- Displays initial balance of ₹2000  
- Withdraw money by clicking on denomination buttons  
- Dynamic UI updates based on state changes  
- Denominations are passed as props and rendered using child components

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/CashWithdrawal
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Visit the app at:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- React class components  
- Props and child components  
- State updates based on user interaction  
- List rendering with `.map()`  
- Component-based architecture
