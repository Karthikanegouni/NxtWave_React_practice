# Password Validator

A simple React app built with **Vite** to validate passwords.

## Features

- Shows an error if password is empty or less than 8 characters
- Hides error if password is 8 or more characters
- Styled with **Styled Components**
- Uses **Roboto** font for heading

## Tech Stack

- React (Hooks)
- Vite
- Styled Components
- JavaScript (ES6+)

## Installation

1. Clone the repo:

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice
```

2. Navigate to project folder:

```bash
cd PasswordValidator
```

3. Install dependencies:

```bash
npm install
```

4. Start the dev server:

```bash
npm run dev
```

Open in browser at the URL shown in the terminal.

## Usage

- Enter a password in the input field
- See error message if invalid
- Error disappears when password is valid
