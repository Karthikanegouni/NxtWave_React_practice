# Money Manager

A full-featured React application to track income and expenses. Users can add transactions by specifying title, amount, and type (Income/Expenses), and view a detailed history and current balance. Built using class-based components and UUID for transaction IDs.

## Live Demo

Click Here: [Money Manager App](https://moneymanagerakg.ccbp.tech/)

- ### Preview

## Features

- Add new transactions with title, amount, and type
- Calculate and display total balance, income, and expenses
- Filter and aggregate transactions by type
- Delete individual transactions from the history
- Controlled form elements with input validations
- Automatically resets form after each submission
- UUID used for unique transaction IDs

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/MoneyManager
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- React class components

- UUID generation for list keys using `uuid`
- Conditional rendering and dynamic state updates
- List filtering and `.reduce()` for calculations

- Basic validation and alert handling
