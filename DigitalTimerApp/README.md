# Digital Timer App

A React-based digital countdown timer that supports customizable time limits and pause/play functionality. Users can set the timer, start or pause the countdown, and reset it back to the default. The timer updates in real-time and displays the status as Running or Paused.

## Live Demo

- [Digital Clock](https://digitaltimerakg.ccbp.tech/)

## Features

- Default timer set to 25 minutes
- Start/Pause functionality with icon toggle
- Timer counts down in mm:ss format
- Reset button restores initial timer state
- Plus/Minus buttons to change timer limit
- Timer disables limit change while running
- Visual feedback for Running or Paused status
- Countdown stops at 00:00 and waits for restart

## Cloning This Project


## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```
