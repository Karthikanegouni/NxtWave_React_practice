# Reviews App

A carousel-style React application that displays user reviews one at a time. Users can navigate through reviews using left and right arrow buttons. This project demonstrates component-based UI, state management, and list iteration with boundary conditions.

## Features

- Carousel to display one review at a time
- Navigation using left and right arrows
- Boundary check: disables previous/next if first/last review is shown
- Dynamic rendering using props

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/ReviewsApp
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- React class components
- List traversal and rendering based on state
- Event handling for navigation
- Conditional disabling of navigation at boundaries
- Passing props and dynamic rendering
