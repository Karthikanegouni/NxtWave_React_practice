# Planets App

A React app that showcases a carousel of planet details using React Slick for elegant sliding animations.

## Live Demo

- ### [Planets App](https://reactslickak.ccbp.tech/)

## Features

- Displays a slider of planets with image, name, and description
- Next/Previous buttons to navigate through planets
- Images use the planet's name for the alt attribute
- Responsive and visually appealing UI

## Functionality

- Utilizes React Slick to display items from the planetsList prop
- Each planet shown in a dedicated card with name, image, and description
- Navigation updates the displayed planet details smoothly
- All components are organized in the `src/components` directory

## Cloning This Project

    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
    cd NxtWave_React_practice/PlanetsApp

## Installation & Running

1. Install dependencies:

   npm install

2. Start the development server using Vite:

   npm run dev

3. Visit:

   http://localhost:5173
