# Events App

A responsive React application that displays event registration details based on user interaction. Users can view the status of selected events such as “Yet to Register”, “Registered”, and “Registrations Closed”. The interface is dynamic and styled with CSS for a clean, user-friendly experience.

## Features

- Displays a list of event cards with name, image, and location
- Shows appropriate view based on the selected event's registration status:
  - No Active Event (initial state)
  - Yet to Register
  - Registered
  - Registrations Closed
- Uses conditional rendering to dynamically switch between views
- Responsive layout with clean styling
- Component-based architecture

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/Events
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Open in your browser:

   ```
   http://localhost:5173
   ```
