# Blog List

A simple React app built with Vite to demonstrate client-side routing using `react-router-dom`. Displays a user profile and a list of blogs on the Home route with navigation support for About and Contact pages.

## Features

- React Router with multiple route navigation
- Home route displays user info and blog list
- NotFound page for invalid routes
- Component-based structure with clean styling
- Responsive layout using plain CSS

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/BlogList
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Open in your browser:

   ```
   http://localhost:5173
   ```
