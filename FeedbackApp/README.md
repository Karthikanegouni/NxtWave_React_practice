# Feedback App

A React app that allows users to provide feedback by selecting an emoji. Once an emoji is clicked, the app displays a thank you screen. This project demonstrates conditional rendering and state management in React.

## Features

- Displays a list of emoji options for feedback  
- On emoji selection, transitions to a thank-you screen  
- Uses props to dynamically load emojis and images  
- Clean and responsive UI with simple animations

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/FeedbackApp
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app using Vite:

   ```bash
   npm run dev
   ```

3. Open the app in your browser:

   ```
   http://localhost:5173
   ```
