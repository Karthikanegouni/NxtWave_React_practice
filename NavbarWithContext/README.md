# Navbar with Context

A React app that lets users toggle between light and dark themes for all routes using React Context.

## Live Demo

- ### [Live Link](https://navbarcontextak.ccbp.tech/)

## Features

- Light and dark theme support with instant toggle
- Theme state shared globally via Context API
- Navbar, Home, About, and Not Found routes adapt UI to current theme
- Theme persists across all routes and updates the entire app instantly
- Responsive UI for all device sizes

## Functionality

- Starts with Light Theme as default
- Clicking the theme image toggles between light and dark modes
- Theme state managed with Context and accessible in every component
- Handles invalid routes with Not Found page

## Cloning This Project

    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git

## Installation & Running

1. Install dependencies:

   npm install

2. Start the development server using Vite:

   npm run dev

3. Visit:

   http://localhost:5173
