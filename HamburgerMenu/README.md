# Hamburger Menu

A React app that implements a popup hamburger menu for smooth site navigation with Home and About routes.

## Live Demo

- ### [Live Link](https://popupak.ccbp.tech/)

## Features

- Responsive hamburger menu popup using React Popup
- Navigation between Home (`/`) and About (`/about`) routes
- Clickable website logo navigates to Home
- Popup opens when hamburger icon is clicked and closes with a close button
- Not Found route for invalid URLs

## Functionality

- Initially shows Home route
- Hamburger icon opens the menu popup
- Menu contains Home and About links for navigation
- Close button closes the popup

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/HamburgerMenu
```

## Installation & Running

1. Install dependencies:

```bash
npm install
```

2. Start the development server using Vite:

```bash
npm run dev
```

3. Visit:

```bash
http://localhost:5173
```
