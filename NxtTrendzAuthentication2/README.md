# Nxt Trendz Authentication 2

A React application with route protection and session-based login using JWT. Ensures authenticated access to specific pages and redirects unauthorized users accordingly.

## Features

- Login authentication with JWT
- Protected routes for Home, Products, and Cart pages
- Redirects unauthorized users to Login page
- Redirects logged-in users away from Login page
- Logout functionality
- Styled using CSS

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/NxtTrendzAuthentication2
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm start
   ```

3. Open in your browser:

   ```
   http://localhost:3000
   ```

## Technologies Used

- React
- React Router
- JavaScript
- CSS
