# Stopwatch App

A simple React-based Stopwatch application with start, stop, and reset functionality. The app tracks elapsed time in seconds and displays it in `mm:ss` format. It demonstrates timer-based state management using React class components.

## Live Demo

- [Stopwatch Live Demo](https://stopwatchak.ccbp.tech/)

## Features

- Start button to begin the stopwatch
- Stop button to pause the stopwatch
- Reset button to clear the time to 00:00
- Elapsed time shown in `mm:ss` format
- Uses `setInterval` to increment time every second
- Visual stopwatch UI with responsive design

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/Stopwatch
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```
