# Gallery App

A responsive image gallery built using React. Users can view a large image and switch between images by clicking on the respective thumbnails.

## Live Demo

- Demo link: [Projects Application](https://GalleryAppbyAk.ccbp.tech)

## Features

- Displays the first image by default
- Clicking on a thumbnail updates the main image
- Highlights the selected thumbnail
- Dynamic rendering using props and reusable components
- Uses `alt` attributes for accessibility

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/GalleryApp
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app using Vite:

   ```bash
   npm run dev
   ```

3. Open in browser:

   ```
   http://localhost:5173
   ```
