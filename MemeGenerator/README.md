# Meme Generator

A React app to create custom memes by overlaying text on images with a selectable font size.

## Features

- Input fields for image URL, top text, bottom text, and font size
- Instantly generates meme with given inputs
- Meme preview shows submitted image and text with selected font size
- Font size options from a predefined drop-down list
- Responsive for all device sizes

## Functionality

- All inputs start empty; font size defaults to first option
- Enter image URL, top text, bottom text, select font size, then click Generate
- Generates meme with image background and positioned top/bottom text
- Text uses selected font size

## Cloning This Project

    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
    cd NxtWave_React_practice/MemeGenerator

## Installation & Running

1. Install dependencies:

   npm install

2. Start the development server using Vite:

   npm run dev

3. Visit:

   http://localhost:5173
