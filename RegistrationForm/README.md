# Registration Form

A basic React form for capturing user details with input validation. Displays error messages for empty fields and shows a success message on valid submission.

## Features

- Controlled inputs with validation
- Shows "Required" message on empty fields
- On successful submission, shows a success message
- Allows submitting multiple responses
- Styled using CSS and responsive layout

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/RegistrationForm
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Open in your browser:

   ```
   http://localhost:5173
   ```
