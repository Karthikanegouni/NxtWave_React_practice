# Notes App

A simple **Notes App** built using React and Styled Components to practice creating, displaying, and managing notes.

## Features

- Add notes with a title and content
- Display list of notes
- Empty notes view when no notes are added

## Demo

![Notes App Demo](https://assets.ccbp.in/frontend/content/react-js-hooks/notes-app-output.gif)

## Setup

1. **Clone the repository**

````bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice
cd NxtWave_React_practice/NotesApp
```
Install dependencies

```bash
npm install
````

Start the development server

```bash
npm start
```

Open in browser

Visit http://localhost:3000 to view the app.
