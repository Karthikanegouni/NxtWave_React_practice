# Match Game

A fast-paced, memory-testing image matching game built using React class components and Vite. Match the correct image before the timer runs out. Includes multiple categories like Fruits, Animals, and Places for added variety.

## Live Demo

Click Here: [Match Game App](https://matchgameakg.ccbp.tech/)

## Features

- 60-second countdown timer
- Score increases on every correct match
- Game ends on incorrect match or when timer hits zero
- Tabs to filter thumbnails by category (Fruits, Animals, Places)
- “Play Again” resets the entire game state
- Responsive layout across all devices

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/MatchGame
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- React class components
- Timer logic with `setInterval` and cleanup using `clearInterval`
- Conditional rendering and dynamic UI updates
- Controlled state for score, timer, active tab, and images
- List filtering and random selection logic
- Component composition with props
- Responsive design with CSS
