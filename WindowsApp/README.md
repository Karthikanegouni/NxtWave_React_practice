# Windows App – React Context

A React app built with Context API to demonstrate global state management for multi-language support without prop drilling.

## Features

- Multi-language support (English, Hindi, Telugu)
- Global state management using React Context API
- Language switcher implemented in the Header
- Dynamic content rendering in Landing, Playtime, and New Ways to Connect sections
- Clean component-based structure

## Cloning This Project

    git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
    cd NxtWave_React_practice/WindowsApp

## Installation and Running

1. Install dependencies:

       npm install

2. Start the development server:

       npm start

3. Visit in your browser:

       http://localhost:3000

## Technologies Used

- React
- Context API (Provider & Consumer)
- JavaScript
- CSS

## What I Learned

- Using React Context to share state across multiple components
- Avoiding prop drilling by centralizing state
- Implementing a multi-language app with reusable logic
- Preparing to refactor with the `useContext` hook for cleaner code
