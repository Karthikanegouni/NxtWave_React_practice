# Music Playlist

A React app that lets users view, search, and delete songs from a music playlist using dynamic Lists and Keys.

## Features

- Displays a dynamic list of songs with images, genre, and duration
- Real-time search input filters songs by name (case-insensitive)
- Each track has a delete button for removal from the playlist
- "No Songs Found" view shown when search yields zero results or all tracks are deleted

1. Install dependencies:

   npm install

2. Start the development server using Vite:

   npm run dev

3. Visit:
