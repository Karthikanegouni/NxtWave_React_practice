# Multilingual Greetings

A React app demonstrating lists, keys, and conditional rendering by switching greeting images for different languages.

## Screentshots

## Features

- Renders a set of language buttons dynamically from a list
- Displays a greeting image corresponding to the selected language
- Highlights the active language button
- Uses unique keys for list items to optimize rendering performance
- Responsive and visually appealing design

## Functionality

- Initially, the English button is active and the English greeting image is shown
- Clicking any language button sets it as active and displays its respective greeting image below
- Greeting image includes an appropriate alt value from the data
