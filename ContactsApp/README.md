# Contacts App

A simple contact management app built with React. Users can add new contacts with name and mobile number, and toggle a contact's favorite status using a star icon. This project demonstrates state handling, form control, list rendering, and conditional UI updates.

## Features

- Add new contacts using a form  
- Mark/unmark contacts as favorite  
- Each contact displayed with name and mobile number  
- Favorite status shown via dynamic star icon

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/ContactsApp
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- React class components  
- Controlled form inputs  
- Dynamic list rendering  
- State updates with previous state reference  
- Conditional rendering of icons based on state
