# Google Search Suggestions

A React app that mimics Google-style search suggestions. As users type in the input field, a filtered list of suggestions appears, and users can autofill the input by clicking the arrow beside a suggestion.

## Features

- Real-time search filtering  
- Case-insensitive matching of input with suggestion list  
- Clickable arrow to autofill search input  
- Clean UI with box-shadow styling and responsive interaction

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/GoogleSearchSuggestions
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app using Vite:

   ```bash
   npm run dev
   ```

3. Open in browser at:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- Props and reusable components
