# Credit Card React Project

A simple React app to display a **credit card** with dynamic inputs for card number and cardholder name using **Styled Components**.

---

## Demo

- Live Demo: [https://ccakarthik.ccbp.tech/](https://ccakarthik.ccbp.tech/)

![Credit Card Demo](https://assets.ccbp.in/frontend/content/react-js-hooks/credit-card-output-v0.gif)

---

## Features

- Live update of **card number** and **cardholder name**.
- Styled with **Styled Components**.
- Responsive layout for all screen sizes.

---

## Installation

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice
cd NxtWave_React_practice/CreditCard
npm install
npm start
```

---

## Usage

- Enter card number in the input with placeholder **Card Number**.
- Enter cardholder name in the input with placeholder **Cardholder Name**.
- Card details update on the credit card in real-time.
