# Cryptocurrency Tracker

A responsive React app to track live cryptocurrency data. Displays each coin's name, logo, and prices in USD and Euro using real-time data fetched from a public API.

## Live Demo

- Live Demo => [Cryptocurrency Tracker](https://cryptotrackerak.ccbp.tech/)

## Features

- Real-time data fetched using `fetch`
- Shows logo, name, and prices (USD & Euro) for each coin
- Responsive design styled with CSS
- Loader displayed using `react-spinners` while fetching data
- Built using both RFC (React Functional Components) and RCC (React Class Components)

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/CryptocurrencyTracker
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Open in your browser:

   ```
   http://localhost:5173
   ```
