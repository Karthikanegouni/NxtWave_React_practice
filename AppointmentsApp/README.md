# Appointments App

A React-based Appointments management application that lets users add, star, and filter appointments. This project demonstrates the use of class components, conditional rendering, form handling, state updates, and list filtering using state.

## Features

- Add new appointments with title and date  
- Star/unstar any appointment  
- Filter to view only starred appointments  
- Form input resets after submission  
- Uses `uuid` for unique appointment IDs  
- Date is formatted using `date-fns`

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/AppointmentsApp
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server using Vite:

   ```bash
   npm run dev
   ```

3. Visit in your browser:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- React class components  
- State management for input fields and appointment list  
- Controlled components for form inputs  
- List filtering based on starred status  
- Toggle functionality using conditional rendering  
- Unique ID generation using `uuid`  
- Date formatting using `date-fns` (`dd MMMM yyyy, EEEE`)
