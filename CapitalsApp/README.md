# Capitals App

A simple React app that displays the corresponding country when a capital city is selected from a dropdown list. Demonstrates usage of forms, lists, and state management in React.

## Features

- Dropdown with a list of capital cities
- Displays the country associated with the selected capital
- First capital is selected by default on initial load
- Clean and responsive UI using CSS

## Cloning This Project

```bash
git clone https://github.com/Karthikanegouni/NxtWave_React_practice.git
cd NxtWave_React_practice/CapitalsApp
```

## Installation and Running

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app using Vite:

   ```bash
   npm run dev
   ```

3. Open in your browser:

   ```
   http://localhost:5173
   ```

## Concepts Covered

- React state management
- Handling `select` dropdown elements
- Mapping data into JSX options
- Dynamic content rendering based on user selection
